Feature overview

One workspace for animation timing.

Everything is built around the real Animator, AnimationClip and Animation Events already used by your game.

Animation state browser

Browse direct clips across controller layers and nested state machines. Animator Override Controller replacements are resolved automatically.

Root-motion preview

Preview imported root translation and rotation while respecting Root Transform Rotation, Position Y and Position XZ bake settings.

Visual event tracks

Organise events into named, coloured tracks. Close markers use separate lanes so each remains selectable.

Frame precision

Snap marker and range edits to source frames, nudge with arrow keys, zoom around the cursor and pan the timeline.

Attack windows

Author normalized hitbox-open ranges directly on Animator states through AnimationCueAttackWindowSmb.

Duration cues

Author start/end ranges for effects such as root-motion scaling or rotation locking using one duration SMB per state.

Audio and VFX preview

Invoke opted-in, attributed methods on an isolated preview clone. Your method remains responsible for its own playback system.

Hitbox display

Show project-provided collider geometry in the viewport and highlight active hitbox slots during an attack window.

Validation

Find missing methods, bad parameters, invalid time ranges, missing receivers and unsupported setup before play mode.

Imported FBX support

Write events through the model importer when the selected clip is embedded in an FBX.

Responsive editor layout

Resize state, preview, inspector and timeline panels. The workspace adapts to narrow and wide editor windows.

No runtime lock-in

Events remain Unity Animation Events. The package does not require a proprietary dispatcher or audio middleware.

Current boundaries

  • Direct AnimationClip states are editable.
  • BlendTree motions are listed but do not expose one unambiguous editable clip.
  • Preview methods must be cosmetic and safe to execute in Edit Mode.
  • Root-motion duration controls must not compete with another OnAnimatorMove owner.
